GTA6 Clipper – Privacy policy

Last updated: 19 November 2026

GTA6 Clipper is a private tool used only by the owner of one YouTube channel. It has no other users.

What it accesses

With the owner's permission (Google OAuth), it uses the YouTube Data API to upload videos to the owner's own channel, change their title, description and visibility, list them, and delete them.

What it stores

Only the IDs and titles of videos it has uploaded to the owner's channel, so it can track what was posted. It does not collect, store or share any data about viewers or other YouTube users, and it does not sell or share any data with third parties.

Google user data

GTA6 Clipper's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
